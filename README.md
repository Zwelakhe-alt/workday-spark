# AI Workplace Productivity Assistant

A modern, responsive AI-powered workplace productivity application designed to help professionals automate common workplace tasks. The application provides tools for generating professional emails, researching topics, and interacting with an AI workplace assistant.

## 📌 Project Overview

**AI Workplace Productivity Assistant** is a frontend-focused SaaS-style web application that brings multiple AI productivity tools into one simple dashboard.

The application allows users to:

- Generate professional workplace emails.
- Summarize topics and articles.
- Receive AI-powered insights and recommendations.
- Interact with an AI chatbot for workplace-related tasks.

No registration, login, or personal information is required to access the application.

## ✨ Features Implemented

### 📧 Smart Email Generator
- Generate professional emails from user-provided information.
- Support multiple tones:
  - Formal
  - Friendly
  - Persuasive
- Display AI-generated email content in an editable output area.

### 🔎 AI Research Assistant
- Enter a topic or article for analysis.
- Generate concise summaries.
- Provide AI-generated insights and recommendations.
- Present research results in a clear and structured format.

### 💬 AI Chatbot
- Interactive workplace AI assistant.
- Users can enter natural-language prompts.
- Displays AI-generated responses in a conversational interface.
- Designed for common workplace productivity tasks.

### 🎨 Dashboard & UI
- Modern SaaS-style dashboard.
- Sidebar navigation.
- Clean black and light-grey visual design.
- Responsive desktop and mobile layouts.
- Structured input and output sections.
- Professional and accessible user experience.
- Responsible AI disclaimer.

## 🛠️ Technologies & Tools

- **React** – Frontend application framework
- **TypeScript** – Type-safe JavaScript development
- **Tailwind CSS** – Responsive styling and UI design
- **Vite** – Development server and build tool
- **Lucide Icons** – Interface icons
- **Lovable** – AI-assisted application development
- **Git & GitHub** – Version control and project hosting

> This project is frontend-focused and does not include a custom backend, authentication system, or user registration.

## 🚀 Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the project directory

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application should be available at:

```text
http://localhost:5173
```

### 5. Build for production

```bash
npm run build
```
